# Евро стекло

Клиентский проект для централизованного сбора материалов компании «Евро стекло» по ранее начатой интеграции с Битрикс24.

## Текущий этап

Только агрегация, регистрация и безопасное хранение исходных материалов. Анализ, мозговой штурм, техническое задание, спецификация и реализация запрещены без нового прямого указания владельца.

## Структура

- `client-materials/private/` — конфиденциальные исходники клиента, исключены из Git.
- `docs/business-processes/` — описание и нормализация бизнес-процессов.
- `docs/research/` — предпринимательские и предметные исследования.
- `docs/specifications/` — технические задания и спецификации.
- `AGENTS.md` — основная инструкция для агентов.
- `CLAUDE.md` — точка входа для Claude.
