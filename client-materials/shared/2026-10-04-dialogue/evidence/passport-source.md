## Формат матрицы и классификация

Строка матрицы: `question_id`, `entity` (lead/deal), `map_point`, `document_ref`,
`asked` (yes/no/unclear), `client_answer` (complete/partial/absent/unclear),
`source_id`, `start_ms`, `end_ms`, `speaker_id`, `evidence_label`,
`conflict_refs`, `scope` (included/excluded).

Один вопрос может иметь несколько реплик и несколько источников. Повторяющиеся
формулировки связываются, а исходные идентификаторы сохраняются. Пропуск в разговоре
и потеря/неразборчивость записи — разные состояния. «Вопрос задан» не означает
«обследование закрыто»: частичный ответ или неразрешённое противоречие остаются открытыми.
Отсутствие найденной фразы само по себе не доказывает, что вопрос не задавался.

PROVEN — прямая цитата с источником и таймкодом; INFERRED — вывод из двух или более
названных источников; UNVERIFIED — «Информации нет»; CONTRADICTED — две несовместимые
цитаты, сохранённые обе. Идентификация клиента требует источника, а не догадки по голосу.
Фрагменты 1С/DNS помечаются excluded и не расширяют текущую работу.

## AssemblyAI: механизм и финансовый контроль

PROVEN: существующий `transcribe --engine assemblyai --lang ru --speakers --format json`
использует `universal-3-5-pro,universal-2`, но сохраняет только text/segments,
без words; до возврата результата пытается удалить серверный transcript.
Источник: `tools/transcribe/engines/assemblyai_engine.py` и `formats.py`, чтение 04.10.2026.
Поэтому запуск этого CLI не удовлетворяет FR-04; не запускать его ради повторной оплаты.

PROVEN: готовый `tools/acc1-scripts/assemblyai-transcribe.py` сохраняет words,
но не задаёт язык/модель и не сохраняет speaker/job ID. Без подтверждения полного
контракта им нельзя объявить FR-03–FR-05 выполненными. Общие инструменты не менять.

Штатный путь — документированный AssemblyAI API/SDK с полным результатом,
явным русским языком и speaker_labels. До запуска требуется подтверждение доступного
кредита и отсутствия неразрешённых списаний. Наличие файла ключа не доказывает его
действительность или баланс. Остаток кредита и расход текущей задачи — UNVERIFIED.
Не более двух запусков транскрибации на этот атом: по одному на каждое видео.
Автоматические оплачиваемые повторы запрещены; существующий job продолжается по ID.

Официальные источники, получены 04.10.2026 через Context7 и официальный сайт:
- https://www.assemblyai.com/docs/billing-and-pricing — “New accounts are provided
  with $50 in free credits”; это условие новых аккаунтов, а не доказательство остатка
  конкретного аккаунта владельца.
- https://www.assemblyai.com/docs/pre-recorded-audio/select-the-speech-model —
  “If no model is specified, the system defaults to using universal-3-5-pro and universal-2.”
- https://www.assemblyai.com/docs/llms-full.txt — word metadata: “Word”, “Start”,
  “End”, “Confidence”; сохранять эти поля без потери.
- https://www.assemblyai.com/docs/openapi.yaml — “Files uploaded via the /upload
  endpoint are immediately deleted alongside the transcript.” Удаление выполняется
  только после локального сохранения и проверки; успешный DELETE подтверждается ответом.

## Порядок исполнения

1. Учёт трёх источников и целостности — выполнен; доказательства в private реестре.
2. Подтвердить остаток тестового кредита, финансовый потолок и документированный
   запуск с words/спикерами. Не исправлять общие транскрибаторы в этом scope.
3. Проверить наличие речи; сделать два производственных запуска AssemblyAI,
   сохранить полный JSON до серверной очистки. Новых paid smoke/eval нет.
4. Принять две расшифровки по FR-04–FR-05; запись пока сохранять.
5. Выполнить сопоставление по FR-06–FR-08 для всех исходных вопросов в scope.
6. Сверить матрицу в трёх кругах: источник → прочие документы → независимый критик.
   Пункты без источника не переводить в целевой бизнес-процесс или настройку.
7. При необходимости подготовить отдельный HTML по FR-09; отделить лиды от сделок,
   включить навигацию к существующим точкам. Существующие карты не переписывать.
8. После принятия расшифровок выполнить разрешённую адресную очистку по FR-10.
9. Проверить безопасный производный HTML и доставить штатным share; Git — только ship.
   Исходные записи/транскрипты не публиковать. Закрыть атом только при полной приёмке.

## Проверки и завершение

Приёмка сборки: прочитать inventory.json; ровно три payload-источника;
пересчитать SHA-256; подтвердить два аудиопотока и один текстовый вход.
Приёмка расшифровок: status completed, непустые text/words, 0 ≤ start ≤ end,
границы внутри длительности; отдельная проверка спорных/смысловых фрагментов.
Приёмка сверки: 100% исходных вопросов в scope имеют строку и обоснованный статус;
нулевое число закрытых ответов без client evidence; все конфликты сохранены.
Приёмка HTML: файл только при пробелах, все его пункты ведут к матрице;
читать удобно с телефона/клавиатуры; безопасный результат проверен после share.
`git diff --check` подтверждает только качество diff, не смысловую приёмку.

Для Spec Kit отсутствуют `.specify/scripts/bash/check-prerequisites.sh`,
`setup-plan.sh`, `setup-tasks.sh`, `resolve-template.sh` и constitution.
Указатель `.specify/feature.json` относится к spec 012 другого предмета.
Не использовать его; не заявлять выполнения specify/plan/tasks/analyze/implement
по одному факту загрузки навыков. Не менять конституцию без её источника.

## Очистка, откат и контрольная точка

До принятия расшифровок ничего не удалять. Удаляются только точные task-owned медиа
из inventory; прежние оригиналы, архивы, зеркала, резервные копии и чужие файлы сохраняются.
Удаление серверного transcript не заменяет локальное, и наоборот.
Штатная recoverable очистка не выдаётся за безвозвратное уничтожение всех копий.
Источник можно скачать повторно и сверить SHA-256; принятый Git-результат откатывается
только новым revert. Ни force, ни reset, ни общий cleanup не разрешены.

Контрольная точка: получить доказательство действующего тестового кредита и доступный
штатный AssemblyAI маршрут без потери words. Отсутствие Spec Kit/dev фиксируется
как ограничение; их настройка не входит в текущую задачу. Без расшифровок нельзя решить, все ли вопросы были
заданы/отвечены, создать содержательный новый вопросник или удалить записи.
