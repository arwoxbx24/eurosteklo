## 5 главных тем комментариев
1. Автоматизация уведомлений сотрудникам (Менеджер ОП, Руководитель ОС/ПТО/ПО/Службы Сервиса) на каждой стадии сделки.
2. SLA/таймеры: настройка изменения стадии сделки и напоминаний через фиксированное число дней (2–3 дня, 3 рабочих дня, 14/90/270 дней).
3. Контактные данные салонов/точек продаж (телефоны и адреса 4 точек Калининграда), не вынесенные в отдельные карточки на доске.
4. Автоматизация документооборота: автоформирование документов, типовые формы договора/КП, согласование с юристом/бухгалтером.
5. Интеграция с учётными системами: номенклатура ↔ 1С, визирование при понижающих коэффициентах, документооборот по частичным отгрузкам и рекламациям.

- Полное совпадение: все текстовые узлы (49 shape + 12 заголовков фреймов + «ЛИД - B2B, B2C» + «Frame 1») присутствуют и в `nodes.csv`, и в клиентском CSV — новых узлов на доске, отсутствующих в CSV, не найдено; узлов CSV, отсутствующих на текущей доске, не найдено.
- Отличия — только формат записи, не содержание: клиентский CSV склеивает многострочные карточки в одну строку через пробел (без `<br/>` → `|`), «100 % оплату» (с пробелом перед %) против «100% оплату» после разбора HTML на доске, для узла «Артиллерийская» CSV хранит ссылку `https://new-format.su/contacts` вторым полем — на доске та же ссылка лежит внутри HTML `data-content` карточки (в `nodes.csv` в текст не вынесена отдельным полем).
