# Claude — проект «Евро стекло»

Перед любой работой прочитай `AGENTS.md`: это каноническая инструкция проекта.

Работай только внутри этой директории. Разрешены только приём, регистрация и безопасное хранение материалов. Не анализируй содержимое, не проводи мозговой штурм, не создавай ТЗ или спецификацию и не разрабатывай интеграцию без нового прямого указания владельца. Конфиденциальные исходники находятся в `client-materials/private/`, не попадают в Git и не публикуются.
