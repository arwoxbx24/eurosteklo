## Вердикт
1. Для первого знакомства годится: живая сделка на экране, 3 вопроса на шаг (`встреча-РОП.md:85`) — наблюдение по `process-states:85`. Для регламентированного ППО под Б24 — нет: нет критериев входа/выхода стадий, исключений, полей, прав, денег, KPI.
2. Из 22 вопросов 8 наводящих/закрытых (Б2, Б3, Б5, В3, А2, `слайды:20-25`), 6 двойных/тройных (А1, А2, Б6, В1, Г2, Б2) — нарушение «avoid leading questions» (`requirements-elicitation:266`).
3. Верифицируемость ≈0: нет колонки «доказательство»; ни один вопрос не требует ID сделки/отчёта/документа. Б7, А4 («в среднем», «примерно») принимают память вместо цифр, которые есть в Б24.
4. «5 почему» нет: Б1, Д1 — один уровень (`requirements-elicitation:268`, `gap-analysis:84`).
5. Один респондент (РОП) на всё: ~40 % вопросов — чужая зона (Б2, Б5, Б6, Г2, Г4, В1, деньги); ассистент ОП, ПО, бухгалтерия, менеджеры-исполнители не в плане интервью (`встреча-РОП.md:19`, `слайды:16`) — против `gap-analysis:85` («validate with users who do the work, not just managers»).

## Нет совсем
Деньги (скидки и согласование, доплата, оплата замера, возвраты — бухгалтерия); права (видимость чужих сделок и салонов); изменение заказа после договора; рекламации (`встреча-РОП.md:149`); тип клиента физ/юр/тендер; план продаж и KPI менеджеров; передачи между отделами (`process-mapping:244`); телефония.

## Предлагаемая архитектура опросника
- M0 Данные до встречи — выгрузка Б24 (лиды, сделки с историей стадий, источники, суммы); каждое утверждение проверяется данными, не видео.
- M1 РОП — лид → договор, квалификация, отказы, KPI, права отдела.
- M2 Менеджер ОП + ассистент — наблюдение 2 живых сделок, ввод из салонов, дубли.
- M3 Руководитель ПО — замер, проект, акт.
- M4 ПТО + производство + снабжение — запуск, «Изготовлено», сроки.
- M5 Сервис/монтаж — ветка монтажа, рекламации, звонки 14/90/270.
- M6 Бухгалтерия/1С — счета, 35 %, возвраты, обмен.
- M7 Собственник — to-be, KPI, границы проекта.

Шаблон вопроса на каждый шаг: триггер → шаги → предусловие → результат (постусловие) → исключения (3 «а если…») → документ → срок (норма/факт) → кто (R/A) → доказательство (ID сделки, файл, отчёт) → сущность Б24. Каждый пункт — «покажите на последней сделке»; ответ без артефакта помечается «со слов, не проверено».
