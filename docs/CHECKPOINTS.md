# Реестр точек отката

Точка отката — утверждённое состояние `main`, к которому можно вернуться. Каждая точка — строка в этом реестре и аннотированная метка `checkpoint/<ГГГГ-ММ-ДД>-<этап>` на `main` (правило П8 регламента [`specifications/2026-09-30-git-collaboration.md`](specifications/2026-09-30-git-collaboration.md)).

- Метки не двигать и не удалять. При сомнении верить полному SHA из таблицы, а не метке.
- Посмотреть состояние: `git show <SHA>` или `git switch --detach <SHA>` (только чтение; вернуться — `git switch -`).
- Отменить принятое изменение: `git revert -m 1 <merge-SHA>` в новой ветке и новым PR в `main`. Force-push и переписывание истории `main` запрещены.
- Реестр только дописывается: новая строка — снизу, старые строки не правятся.
