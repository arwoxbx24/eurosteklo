## Как собирать
- `python3 docs/ppo/build_all.py` — собирает все процессы и оглавление из фрагментов `<процесс>/_parts/` (код — `docs/ppo/_common/build_proc.py`, стили — `_common/base.css`, масштаб — `_common/zoom.html`).
- Фрагменты процесса: `karta.svg.html`, `tochki.html`, `sostoyaniya.html`, `pasport.html`, список точек `TOCHKI.md`, фактчек `FACTCHECK-*.md`.
- Карта сделок склеивается из трёх слоёв: `python3 docs/ppo/sdelki/_parts/stitch.py` (контракт `KARTA-CONTRACT.md`) — так же можно дробить новые процессы для параллельной работы.
- Проверки перед коммитом: все вопросы подробной версии есть в короткой; все номера точек ведут на карту и обратно; поиск ПДн (телефоны, почты, фамилии) = 0; скриншоты playwright (`/opt/node22/lib/node_modules/playwright`, chromium `/opt/pw-browsers/chromium`).
