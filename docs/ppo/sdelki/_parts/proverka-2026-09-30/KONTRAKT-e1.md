## Общие правила
1. Каждый блок правит ТОЛЬКО свои файлы (ниже). `karta.svg.html` руками не править — его собирает `stitch.py` (сборку делает сводящий).
2. Номера существующих точек не менять, точки не удалять. Новые точки — только 25…29 (метки С25…С29).
3. Каждое изменённое утверждение — с источником (`<small class="src">…</small>` или `title`): id Miro / ТЗ ФТ-n / ячейка статусной модели. Нет источника — «Информации нет».
4. Пометка 1С — дословно: «1С — неизвестно, уточнить».
5. Портал клиенту не выносим; вопросы о настройке портала — не клиенту (переносятся в `audit.md` своего блока).
6. Формулировки доски — дословно, без нормализации.
7. Формат маркера точки на карте (как у существующих, копируй): `<g class="pt"><title>Точка N: текст</title><circle cx=".." cy=".." …/>…</g>`; слой определяется по Y (см. `<!-- layers: A<… B<… -->` в karta.svg.html / KARTA-CONTRACT.md).
