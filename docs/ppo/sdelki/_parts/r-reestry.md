Источники: `docs/ppo/konflikty/k1-prepost.md` (П-01…П-45), `k2-forks.md` (Р-01…Р-40), `k3-conflicts.md` (К-01…К-37), `docs/ppo/05-raci-reglamenty.md` (далее «05»), `docs/as-is/2026-09-28-portal-as-is.md` (далее «ASIS», только справочно — для будущего аудита интегратора), `docs/ppo/lidy/_parts/TOCHKI.md` (точки лидов 1–16 — исключены).
Решения владельца (`docs/ppo/00-resheniya-vladeltsa.md`): базовая линия — ТЗ, не портал; вопросы «как настроено в портале» клиенту не задаём — они в колонке «для аудита интегратора»; 1С — только в сделках, блок «неизвестно — уточнить»; доска — предположение руководителя, не истина.

## Как читать

- Id Miro: узлы — последние цифры с префиксом `…` (полные id — `k1-prepost.md`, приложение А); комментарии `к.…73хх` = `34587646851964773хх`.
- Метка (как в реестрах): **на доске** — есть на доске, не хватает деталей; **не знаем** — источник молчит («Информации нет»); **противоречие** — два слоя/места говорят разное; **со слов** — только запись интегратора или наш производный документ.
- Тип: предусловие / постусловие / развилка / роль / срок / правило / документ / сущность / событие.
- Дубли сведены: одна строка = одна проблема, в «Основании» все ID П/Р/К.
- Исключено как покрытое лидами (TOCHKI 1–16): каналы и источники (П-03, К-28), разбор лида и его срок (П-02, Р-07), B2B/B2C в лиде, недозвон по лиду (Р-06), повторная заявка (Р-08 — дубль клиента), реквизиты при конвертации (П-01, К-26), постусловие конвертации и порядок «Предв. расчёт/Заявка» на входе (К-02, П-44 — точка 9), «единый формат»/«структура карточек» (К-32 — точка 10), воронка отказников и 4 причины (П-05, Р-01, Р-02, К-13 — точка 11), «Закупка отложена» (Р-03 — точка 12). Если остаток проблемы касается сделки — он оставлен в строке с пометкой «часть — точка N лидов».
- Колонка «Для аудита интегратора»: пометка **[аудит]** — вопрос о настройке портала; клиенту НЕ задаём, копим для будущего архитектурного аудита. «—» — портального вопроса нет.
- Все строки — БЛОКИРОВАНЫ до ответа клиента (закон блокировки `AGENTS.md`).
