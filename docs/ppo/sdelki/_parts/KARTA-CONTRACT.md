# Контракт сборки карты «Сделки» из трёх слоёв (параллельно)

Каждый слой — отдельный файл-фрагмент: `karta-A.svg.html`, `karta-B.svg.html`, `karta-C.svg.html`.
- Содержимое: ТОЛЬКО SVG-элементы (без <svg>), в ЛОКАЛЬНЫХ координатах слоя: x 0…2600, y от 0 вниз.
- Первая строка: `<!-- height: H -->` — высота слоя в px.
- Общий <defs> (стрелки) НЕ объявлять — использовать готовые маркеры: `marker-end="url(#arr)"` (чёрная стрелка), `url(#arrg)` (серая). Их объявит сборщик.
- Стили: только атрибуты (fill, stroke, font-size…), без <style>. Шрифт font-family="system-ui,sans-serif", текст ≥14px.
- Рамка слоя: прямоугольник 0,0,2600,H с заголовком слоя слева сверху.
- Узлы доски: <g><title>id Miro …</title>…</g>; узлы ТЗ: <title>ТЗ ФТ-n: «цитата»</title>; статусы: <title>Статусная модель, ячейка …</title>.
- Точки — строго ПЛОСКО, по одной строке, НЕ внутри других <g>:
  `<g class="pt"><title>Точка N: суть</title><circle cx="X" cy="Y" r="16" fill="#d93025" stroke="#fff" stroke-width="2"/><text x="X" y="Y+5" text-anchor="middle" font-size="13" font-weight="800" fill="#fff">СN</text></g>`
  (N — число без «С»; cx/cy/x/y — числа в локальных координатах слоя).
- Никаких ФИО/телефонов/почт. Доска Miro — только чтение.

Распределение точек (TOCHKI.md):
- Слой A (доска Романа): С1, С3, С4, С5, С7, С8, С10, С11, С13, С14, С15, С16, С19, С21, С23, С24
- Слой B (ТЗ 2024–2025 + статусная модель Б24 ↔ 1С): С2, С6, С9, С12, С17, С18, С20, С22
- Слой C (портал): точек нет.
