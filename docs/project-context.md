# Контекст проекта

## Клиент

«Евро стекло».

## Цель

Продолжить ранее начатую разработку интеграции с Битрикс24, начиная с восстановления и актуализации бизнес-процесса и проектной документации после смены руководства компании.

## Полученный вход

- англоязычная mind map;
- описание бизнес-процесса, вероятно оформленное нестандартным способом;
- архив материалов по короткой ссылке клиента.

## Карта источников

- `Евростекло.csv` — основной структурный источник для будущей склейки процесса.
- `Евростекло.jpg` и `Евростекло (1–4).jpg` — дополнительные визуальные источники для сверки и восстановления связей.
- `sharex-win-ifBLjU.mp4` — визуальный материал без слышимого звука; транскрипция речи невозможна.

## Текущая граница

Только приём, регистрация и упаковка материалов. Анализ, вопросы, мозговой штурм, исследования, ТЗ, спецификация, проектирование и реализация не входят в текущий объём.

## Следующий этап после отдельной команды владельца

Извлечь визуальную информацию из видео, объединить её с CSV и всеми JPG-скриншотами, после чего подготовить документацию бизнес-процесса. До отдельной команды этот этап не выполняется.

## Статус утверждений

- `PROVEN` — прямо следует из материалов клиента или решения владельца;
- `INFERRED` — обоснованная интерпретация;
- `UNVERIFIED` — требует подтверждения;
- `CONTRADICTED` — расходится с другим источником.
