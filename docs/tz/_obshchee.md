## Что сделать

Для КАЖДОГО вопроса банка в диапазоне блока — ровно одна строка TSV. Ни один вопрос не пропускать, новых id не выдумывать.

Статусы (только из списка):
- `ОТВЕЧЕН` — клиент ответил по существу.
- `ЧАСТИЧНО` — ответ неполный или уклончивый.
- `БЕЗ-ОТВЕТА` — интервьюер спросил, клиент не ответил.
- `НЕ-ЗАДАН` — тема в диалоге не звучала.
- `ССЫЛКА` — пункт с `data-see`; в `ответ_кратко` — `см. <значение data-see>`.
- `ВНЕ-1С` — вопрос про 1С (слово «1С» в тексте вопроса или точка целиком про 1С). Владелец 04.10: «блок 1C остается пока что за скобками».
- `ВНЕ-DNS` — вопрос про DNS. Владелец 04.10: «Блок DNS остается пока на выходе».

Если пункт подходит под несколько статусов: `ВНЕ-1С`/`ВНЕ-DNS` старше `ССЫЛКА`, `ССЫЛКА` старше остальных.
Для `ВНЕ-1С`, `ВНЕ-DNS`, `ССЫЛКА`: `противоречие` = `нет`, `источник_противоречия` = `—`, `вопрос_клиенту` = `—`.

## Формат ответа — строго

Первая строка ответа — `---TSV---`, последняя — `---END---`. Между ними: строка заголовка и строки данных, разделитель — символ табуляции, без кавычек, без табуляций и переводов строк внутри ячеек.

Заголовок (дословно):
`id	статус	запись	таймкод	спикер	ответ_кратко	противоречие	источник_противоречия	вопрос_клиенту`

- `id`: `<П>-t<N>-q` для главного вопроса, `<П>-t<N>-e<M>` для пункта; `<П>` = `L` (лиды) или `S` (сделки).
- `запись`: `GR8`, `Hkb` или `—`.
- `таймкод`: префикс строки расшифровки, где начинается ответ (для `БЕЗ-ОТВЕТА` — где прозвучал вопрос), формат `ЧЧ:ММ:СС`, дословно из файла; иначе `—`.
- `спикер`: метка из той же строки; иначе `—`.
- `ответ_кратко`: ≤100 знаков, пересказ слов клиента без домыслов; для `НЕ-ЗАДАН` — `—`.
- `противоречие`: `да` или `нет`. `да` — ответ клиента расходится с текстом вопроса/точки, с `TOCHKI.md`, с `data.md`, с анкетой sct (если она во входах блока) или с другим местом диалога.
- `источник_противоречия`: при `да` — `<файл>:<номер строки>` (`TOCHKI.md:12`, `data.md:40`, `sct:118`) или `<запись> <таймкод>`; при `нет` — `—`.
- `вопрос_клиенту`: для `ЧАСТИЧНО`, `БЕЗ-ОТВЕТА`, `НЕ-ЗАДАН` и для любой строки с противоречием `да` — вопрос клиенту простыми словами, ≤150 знаков, без внутренних кодов и терминов «доска», «ТЗ», «СМ»; иначе `—`.

Закон проекта: нет источника — нет утверждения. Ответ без таймкода не ставится в `ОТВЕЧЕН`; догадки запрещены — сомнение = `ЧАСТИЧНО`.

После `---END---` — одна строка: `итого: строк=<число> ОТВЕЧЕН=<n> ЧАСТИЧНО=<n> БЕЗ-ОТВЕТА=<n> НЕ-ЗАДАН=<n> ССЫЛКА=<n> ВНЕ-1С=<n> ВНЕ-DNS=<n> противоречий=<n>`.
