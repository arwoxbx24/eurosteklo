# Доставка независимого аудита Евростекла через Git

Внутренний паспорт доставки, не клиентское ТЗ. Атом eurosteklo-a58.
Основание: прямое поручение владельца 05.10.2026 отгрузить результат в репозиторий.

Цель: проверенные производные аудита доступны владельцу в закрытом arwoxbx24/eurosteklo.
Архитектура: существующие HTML и TSV; без приложения, базы данных, CRM или публикации сайта.
Область: docs/review/2026-10-05-consistency/index.html, utochneniya.html, evidence.tsv и этот паспорт.
Исходная версия аудита: PR33 head65993b5088ef6c685f0f839e4c54ce6f68cf97d9.
Копии входных материалов сохранены отдельно в собственном именованном Git stash
4065e27d5186f3057788d799392c200c5bc34d83; в доставляемый коммит они не входят.

Порядок: проверить отдельную ветку и private origin; изолировать входную копию;
проверить только разрешённые файлы, источники и отсутствие секретов;
создать scoped commit; доставить обязательным штатным ship;
проверить remote SHA, PR и содержимое трёх производных; закрыть атом как сдано на приёмку.

Приёмка:
- 110 уникальных исходных ID, 27 уникальных строк ответа, TSV 111 строк с заголовком.
- 0 повторов шаблона «Правильно ли», 0 фиктивных ссылок на локальные вопросы.
- git diff --check; gitleaks git --pre-commit --staged --redact --no-banner.
- git diff --name-only origin/main...HEAD ограничен указанной областью.
- После доставки blob каждого производного на remote совпадает с принятым локальным файлом.
- Статус рабочей ветки чистый; реальная доставка и приёмка клиентского процесса различаются.

Граница: вывод полноты отрицательный; акустическая и полная смысловая приёмка UNVERIFIED.
Клиентское ТЗ, прежние карты, исходные записи, Bitrix24, сайт и чужой CLAUDE.md не изменять.
Для сохранения общего рабочего дерева используется документированный ship --handover:
штатная Git-доставка без live sync и удаления рабочей копии.
Откат: только новый PR с revert собственного доставленного коммита; не переписывать main,
не удалять исходники и не восстанавливать именованный stash поверх чужих изменений.
Условие завершения: удалённые файлы проверены, результат Git-доставки зафиксирован в атоме.
