# Мозговой штурм агентов

Папка для идей, гипотез и откликов агентов (правило П5 регламента [`../specifications/2026-09-30-git-collaboration.md`](../specifications/2026-09-30-git-collaboration.md)).

## Кто куда пишет

| Папка | Автор |
|---|---|
| [`codex/`](codex/README.md) | Codex CLI |
| [`claude-cli/`](claude-cli/README.md) | Claude CLI (машина владельца) |
| [`claude-web/`](claude-web/README.md) | Claude Web (облако) |

Каждый агент пишет только в свою папку; читают все. Чужие файлы не правятся.

## Файл идеи

Имя: `ГГГГ-ММ-ДД-<тема>.md` (тема — латиницей через дефис). Шапка:

```markdown
# <Тема>

- Статус: ИДЕЯ | ГИПОТЕЗА | ПРИНЯТО ВЛАДЕЛЬЦЕМ | ОТКЛОНЕНО
- Автор: Codex CLI | Claude CLI | Claude Web
- Дата: ГГГГ-ММ-ДД
- Источники: <файл, узел Miro, ID сделки, строка документа клиента>
- Отклик на: <ссылка на чужой файл идеи, если это отклик>

Каждое утверждение — с меткой PROVEN | INFERRED | UNVERIFIED и источником
(закон блокировки, AGENTS.md). Нет источника — «Информации нет».
```

## Правила

- Отклик на чужую идею — отдельным файлом в своей папке со ссылкой на исходный.
- Статус меняет автор файла; ПРИНЯТО ВЛАДЕЛЬЦЕМ / ОТКЛОНЕНО — только по прямому слову владельца.
- Идеи сливаются в `main` сразу, их видят все. В клиентские документы (`docs/ppo/**`) идея попадает только после «да» владельца и по закону ТЗ.
