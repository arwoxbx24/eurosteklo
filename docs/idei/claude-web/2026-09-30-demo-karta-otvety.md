Режим: BRAINSTORM. Методологии: 5W1H, Brainstorm/7T, Comparison Matrix + SWOT, MoSCoW.

## 1. Переформулировка (5W1H)
Владелец на демонстрации Роману не может быстро показать «это ваша доска, а это прежнее ТЗ», потому что слои похожи, а служебные пометки (скобки-комментарии, «наша разметка», «—», ссылки на id) создают шум; и не может быть уверен, что ответы встречи не потеряются и что он ничего не забыл спросить.

## 2. Тема 1 — «где доска, где ТЗ» и шум на схеме
Варианты:
- А. Цвет слоя: фон и шапка слоя А — тёплый (жёлтый, «доска клиента»), слой Б — холодный (синий, «ТЗ 2024–2025»), слой В — серый; крупная плашка-легенда над картой. Просто, работает сразу.
- Б. Переключатель вида над картой: «Доска Романа | ТЗ 2024–2025 | Обе» — показывает один слой на весь экран. Для показа клиенту — идеально (одна картинка за раз).
- В. Режим «Показ клиенту» (кнопка): скрывает служебное — курсивные пометки, скобки-комментарии, «наша разметка», источники/id; остаются узлы, стрелки, роли и красные точки. Служебное видно в «Рабочем» режиме и при наведении.
- Г. Комментарии доски — стикеры: вместо скобок «[» маленькие жёлтые листочки (как в Miro) с номером; полный текст — при наведении.
- Д. (7T-инверсия) Две отдельные карты-страницы «Доска» и «ТЗ» — HOLD: новые страницы/ссылки (закон ссылок), двойное сопровождение.

| Вариант | Ценность | Сложность | Скорость | Риск | Итог |
|---|---|---|---|---|---|
| А Цвет слоёв | M | L | H | L | берём |
| Б Переключатель слоёв | H | M | H | L | берём |
| В «Показ клиенту» | H | M | H | M (спрятать важное) | берём |
| Г Стикеры вместо скобок | M | M | M | M (перерисовка 124 подписей) | позже |
Лучший: **А + Б + В** (движок, без правки содержания карт). SWOT: S — клиент видит одну понятную картину; W — служебное скрыто, владелец должен помнить про «Рабочий» режим; O — тот же режим для будущих процессов; T — скрыть то, что клиент должен увидеть (снимается правилом: красные точки и роли не скрываются никогда).

## 3. Тема 2 — клик по красной точке
Критика идеи владельца: верно — всплывающая панель показывает клиенту формулировки «А если…» и статусы на общем экране; отдельное окно — у владельца.
Варианты: А. Вернуть: клик → отдельная страница вопросов (как было). Б. Панель только по Alt-клику (скрытая функция). В. Панель убрать совсем.
Лучший: **А** (по умолчанию отдельная страница); панель «Кто за что отвечает» по ролям оставить — там только содержимое карты. Б — не делать (скрытое поведение путает).

## 4. Тема 3 — ответы не теряются
Факты: ответы сейчас в памяти браузера (localStorage) — переживают перезагрузку в том же браузере [VERIFIED тестами e3/e4]; при открытии файлами в Chrome хранилище общее для всех файлов, в Firefox может быть своё на файл, при другом браузере/компьютере — пусто [HYPOTHESIS]. Файл в репозитории страница сама изменить не может (безопасность браузера) [VERIFIED].
Варианты:
- А. Автосохранение в файл: кнопка «Выбрать файл ответов» один раз → дальше каждая галочка сразу пишется в этот .md (Chrome/Edge, File System Access) [HYPOTHESIS: работает для страниц, открытых файлом — проверить].
- Б. «Загрузить ответы (.md)»: после нового скачивания репозитория выбираете сохранённый файл — все галочки и статусы восстанавливаются.
- В. Черновик в памяти + напоминание сохранить (см. тема 4).
- Г. Сервер/облако — HOLD (новая инфраструктура, данные клиента вне контура).
Лучший: **Б + В обязательно, А — как ускоритель в Chrome**. Файл ответов — источник правды; память браузера — черновик.

## 5. Тема 4 — «всё ли спросил?» при закрытии
Критика идеи владельца: браузер при закрытии вкладки показывает только своё стандартное окно «Покинуть страницу? Изменения могут не сохраниться» — свой текст («всё ли спросил у клиента?») туда вставить нельзя [VERIFIED: ограничение современных браузеров]. Поэтому нужен свой шаг «Завершить встречу» внутри страницы, а стандартное окно — только как страховка.
Варианты:
- А. Кнопка «Завершить встречу» (вверху и внизу): окно-сводка — «Отвечено N из M точек повестки; без статуса: т.5, т.10…; отмечено “А если…”: K» → кнопки «Вернуться и спросить» / «Сохранить ответы (.md) и завершить». Ничего не обязательно — только информирует.
- Б. Страховка при закрытии: если есть изменения, не сохранённые в .md, — стандартное окно браузера.
- В. Счётчик в углу «повестка: 6/9 · не сохранено» — всегда виден, подсказывает без окон.
Лучший: **А + Б + В**. Пустые галочки — нормально: сводка их показывает, но не требует.

## 6. MoSCoW
- MUST: клик по точке → отдельная страница (т.2А); «Завершить встречу» + сводка + сохранение .md (т.4А); страховка при закрытии (т.4Б); «Загрузить ответы (.md)» (т.3Б); цвет слоёв + переключатель слоёв (т.1А, 1Б).
- SHOULD: режим «Показ клиенту» (т.1В); счётчик (т.4В).
- COULD: автосохранение в файл в Chrome (т.3А).
- WON'T сейчас: стикеры вместо скобок (т.1Г), отдельные страницы слоёв (т.1Д), сервер (т.3Г).
