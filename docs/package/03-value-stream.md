# Поток создания ценности «Евростекло»: лид → сделка завершена

Дата: 28.09.2026. Документ производный (навык ba-value-streams). Название потока — от получателя (заказчик), не от организации.

- Имя потока: «Путь заказчика: от запроса до завершённой сделки» — `PROVEN` (метод ba-value-streams; получатель Заказчик — 02-concept-model.md №9).
- Объект ценности (Value Object): Сделка — `PROVEN` (02-concept-model.md №2).
- Получатель (Recipient): Заказчик (Party, 02-concept-model.md, №9) — `PROVEN` (02-concept-model.md №9; nodes.csv).
- Триггер: Лид получен из канала (Сарафан / vk.ru / Telegram / Авито / салон) — PROVEN (nodes.csv; edges.csv:6,7).
- Итог (Outcome): Сделка завершена (закрывающие документы, контрольный сервис) — `PROVEN` (nodes.csv; comments.json …7345).

Стадии потока выведены из узлов доски Miro (nodes.csv, фреймы стадий сделки) и подтверждённых связей edges.csv; роли — из узлов-действий доски; SLA и уведомления — из комментариев клиента (comments.json). Прямые коннекторы между фреймами стадий отсутствуют (SRT фиксирует текущий портал), поэтому линейный порядок стадий — UNVERIFIED, где это оговорено.
