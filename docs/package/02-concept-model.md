# Модель понятий «Евростекло»: словарь сущностей

Дата: 28.09.2026. Документ производный (навык ba-concept-model, иерархия классификации — Capsicum Triad: Party / Record / Resource).
Назначение: единый словарь бизнес-объектов потока «лид → сделка завершена», используемых в карте возможностей, потоке создания ценности и документе для клиента.

Статусы по закону блокировки. Каждая сущность — с типом, определением, источником и статусом. Содержимое не выдумывается сверх источников.

## 1. Иерархия классификации

Использован вариант A (Capsicum Triad): `Party` (кто действует), `Resource` (что передаётся/производится), `Record` (что документирует событие). Выбор согласован с методологией навыка; источник клиента иерархию не фиксирует, поэтому итоговое подтверждение — на встрече с клиентом (`UNVERIFIED`, метод ba-concept-model; источник клиента отсутствует).

## 3. Жизненные циклы

- Сделка: предварительный расчёт → заявка → договор → подписание → предоплата → в производстве → изготовлено → отгрузка → сделка завершена; ветка монтаж параллельно отгрузке (PROVEN, nodes.csv; порядок/ветка — UNVERIFIED, node).
- Замер: счёт на замер → предварительная оценка → задание на замер → распределение → чертёж и спецификации (PROVEN, edges.csv:8–12).
- Заказ: заказ в производство → производственный график → изготовлено (PROVEN, nodes.csv).
- Сервис: сделка завершена → контрольный звонок 14/90/270 (PROVEN, comments.json …7345).

## 4. Взаимосвязи сущностей

- Лид —(конвертация)→ Сделка — содержит Заказ; Заказ —(производство)→ Изделие/готовность (Association, PROVEN, nodes.csv; edges.csv).
- Заказ —(использует)→ Номенклатура; Номенклатура —(наличие)→ внутреннее потребление (Association, PROVEN, nodes.csv).
- Сделка —(сопровождается)→ Документ сделки; Сделка —(оплата)→ Оплата; Сделка —(СЛА)→ SLA-контроль (Association, PROVEN, nodes.csv; comments.json).
- Салон и канал —(источник)→ Лид (Association, PROVEN, edges.csv:6,7).
- Сотрудник/роль —(исполняет)→ стадии Сделки (Association, PROVEN как связи на доске; маппинг на пользователей Б24 UNVERIFIED).

## 6. Пробелы и вопросы

- Место формирования и хранения документов (Б24 или 1С) источником не подтверждено — «Информации нет», вопрос клиенту.
- Маппинг ролей (Менеджер ОП и др.) на конкретных пользователей/группы Битрикс24 не установлен — роли процесса `PROVEN` (nodes.csv), сам маппинг — «Информации нет», вопрос клиенту.
- Интеграция 1С присутствует в портале (коннектор и поля — PROVEN, frame_0017, frame_0033, frame_0034), но порядок, конфиг и направление обмена номенклатурой/заказами/статусами не задокументированы — UNVERIFIED, вопрос клиенту.
