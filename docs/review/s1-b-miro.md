## Метки статусов
`PROVEN` — прямо следует из источника · `INFERRED` — обоснованная интерпретация · `UNVERIFIED` — требует подтверждения · `CONTRADICTED` — расходится с другим источником (не использована). Покрытие элемента = факт источника отражён хотя бы в одном документе (`docs/specifications/2026-09-28-eurosteklo-spec.md`, `docs/package/*`, `docs/as-is/*`).

Примечание о нумерации FR: `specs/001-client-package/spec.md` и бизнес-спека `2026-09-28-eurosteklo-spec.md` используют разные наборы FR. Здесь **S1-B / FR-008** — это номер из `specs/001` (покрытие источников). Ссылки на «FR-NN» внутри таблиц покрытия — это номера **бизнес-спеки** (там FR-008 = воронка отказников). Пересечений логики нет, нумерация самостоятельная.
