## Препятствия

1. Платформа допускает три дочерних потока, четвёртый запуск отвергнут: `collab spawn failed: agent thread limit reached`. Фактически A/B/C шли параллельно, E выполнен освободившимся автором A параллельно с оставшимися B/C. D выполнен одним автором после A–C; рецензия A/B/C/E шла параллельно с D. После D получены результаты всех пяти назначенных ролей по D. Строго четыре различных одновременных дочерних агента не выдаются за состоявшийся запуск.
2. В начале ошибочная остановка опиралась на недоступность Beads. Запрет §7–8 отражён строкой `skip-step: csb — журнал bd`; дальнейших обращений к bd не было. Историческая диагностика: `bd --readonly list --status=in_progress --json` вернул `Error: failed to open database: embeddeddolt: open db: failed to load database "eurosteklo": openat LOCK: read-only file system`, код 1. Корень базы вне разрешённой записи. Собственный атом не создан и не закрыт; Beads-гейт не объявляется успешно пройденным. Это не основание считать файловое ТЗ невыполненным или отменять независимые проверки.
3. Ограничения источников оставляют 11 НЕ ПРОВЕРЕНО; они не превращены в ФАЛЬСИФИКАЦИЮ. Права процесса, загрузка конкретных навыков новым Codex и восстановление tmux также не удостоверены; условный вердикт E сохранён.
4. CE выполнен штатными ролями в существующих контекстах; внешняя модель не запускалась, поскольку сеть разрешена только E и официальным страницам OpenAI. Правки исходных A–D рецензией запрещены; только автор C дополнил своё приложение командным выводом. Независимая приёмка Claude CLI по §9 ещё не наблюдалась.
5. Владелец в 10:20 отменил сокращение 10:14. Пропуска ce-doc-review или speckit по причине «нет времени» нет. Запрещённые шаги навыков явно перечислены в их артефактах.
