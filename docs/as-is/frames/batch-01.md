## Наблюдения (только по видимому)
- Портал: `evrosteklo.bitrix24.ru`, компания в шапке — «ЕВРОСТЕКЛО».
- Воронка лидов: «Не обработан» → «В работе» → «Обработан».
- Воронка сделок «Общая»: «Квалификация заявки» → «Подготовка и согласование д...» → «Оплата» → «Монтаж» → «Сделка провалена» → «Рекламация» → «Исполнена».
- Воронка сделок «Активные продажи»: «Предварительная заявка» → «Замеры и проектирование» → «Согласование сделки» → «Оплата» → «Производство» → «Монтаж» → «Закрытие сделки».
- В карточках сделок используется интеграция «BitrixGPT» (комментарии-выжимки по звонкам).
- Роботы на большинстве стадий помечены «Настройка роботов возможна только в дизайнере Бизнес-процессов» — то есть управляются через дизайнер БП, не через типовой конструктор роботов CRM.
- Найден настроенный робот «Контроль» (уведомление руководителю о провале сделки с плейсхолдерами ID/Название/Сумма/Ответственный) и робот «Поставить задачу» (кому — «Ответственный мен...», обрезано).
