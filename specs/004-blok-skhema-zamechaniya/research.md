# Research: спецификация 004

Основание пересмотра — владелец 28.09: «строго через готовое решение, никаких кастомизаций … тестируем, пока не выбрали»; выбор «Набор + шрифт и цвет» (AskUserQuestion 28.09). Готовое решение — `clients/tools/drawio-ai-kit`, навык `skills/drawio-bpmn/SKILL.md`.

## R1. Как строится схема

- **Decision**: штатный порядок набора — `scaffold bpmn/build_bpmn.mjs -o docs/process/bpmn/build.mjs` → правка только разницы (дорожки, фазы, шаги из `data.md` и текущего `.drawio`) → `node build.mjs` (сам печатает validate и список issues) → итоговый `validate` (SKILL.md:58-69). Координаты руками не задаются.
- **Rationale**: ручная правка XML — кастомизация в обход набора (владелец 28.09). Содержание процесса берётся из текущей схемы и `data.md`, не меняется (FR-011).
- **Alternatives considered**: ручная правка `.drawio` через opencode — отклонено владельцем; восстановить старый `build.mjs` — сорвалось (spec 003 А7).

## R2. Шрифт ≥16 px и чёрный цвет — единственная правка поверх набора

- **Decision**: в конце `build.mjs`, после `d.mxfile()`, одна замена в строке XML: `fontSize` <16 → 16 (заголовки дорожек и фаз — 18), `#232F3E`/`#5A6B7B` → `#1A1A1A`. Строка помечается комментарием `ponytail:`.
- **Rationale**: шрифта в API набора нет (grep `fontSize` по `docs/api-cheatsheet.md`, `rules/principles.md` = 0), цвет #232F3E штатный (`src/bpmn.mjs:13`); выбор владельца «Набор + шрифт и цвет».
- **Alternatives considered**: только набор — отклонено владельцем.

## R3. Номера, документы, пунктир — штатными средствами

- **Decision**: номер проблемного места — штатный кружок `badge` набора на связи, входящей в проблемный шаг (`src/builder.mjs:657-665`; `step` — лишь текстовый префикс «N.», :617-619, не маркер); зелёный #3F7D20 перекрашивается в #D90000 правкой цвета R2; P8, P9 («все фазы») — только в списке; документ клиента — значок каталога `document` (`search "document"` → General) в дорожке «Клиент»; связь документ→шаг — `d.link(…, { dash: true })`; список «Проход с клиентом» и строка источника — штатный `box` под пулом.
- **Rationale**: всё есть в наборе, без своих фигур.
- **Alternatives considered**: `shape=document`/`ellipse` руками — кастомизация, отклонено.
