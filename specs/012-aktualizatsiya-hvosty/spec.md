### §3 Архитектура

- **Р-1. Объекты Codex разбирает Claude.** Слово владельца 01.10 снимает для О5–О8 запреты «`[CODEX]` — не трогать» и «чужие ветки не трогать». В чужую ветку не коммитим: коммит передачи — на отсоединённой вершине.
- **Р-2. Незавершённое сохраняется, затем публикуется как архив.** Коммит передачи (автор `Claude CLI`) → метка `archive/codex-<имя>-wip` → проверка состава `git diff --stat` → `gitleaks` = 0 → push метки (репозиторий приватный; образец `archive/claude-00v`). Только после push копия и ветка убираются.
- **Р-3. Ветки снимаются `git branch -d`.** Вершины всех четырёх веток — предки `main`; `-d` снимает и строки `branch.<имя>` конфига. `update-ref -d` и `-D` не применяются.
- **Р-4. Отказ прав — стоп по объекту.** Объект остаётся, в его запись — дословный отказ, остальные объекты исполняются; повтор другой формой запрещён.
- **Р-5. Документы не правятся.** Пометка `a0s` вопреки слову «никаких ручных правок» и закону согласования (7 документов без «да» владельца) — отвергнута; запись закрывается с числами.

Отвергнуто: массовое закрытие без доказательств; `--force`; вливание правок Codex в `main` (регламент изменён 89 коммитами); локальная метка без копии на GitHub (потеря при утрате диска).
